# Interfaces (SAP HANA)

---

Interfaces specific to the SAP HANA data provider. [ISapHanaBulkDbSetting](/interface/saphana/isaphanabulkdbsetting) extends [IDbSetting](/interface/idbsetting) with a write-strategy setting for the bulk operations, and ships in [RepoDb.SapHana.BulkOperations](https://www.nuget.org/packages/RepoDb.SapHana.BulkOperations) rather than the core [RepoDb.SapHana](https://www.nuget.org/packages/RepoDb.SapHana) package.
