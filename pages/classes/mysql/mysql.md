# Classes (MySQL)

---

RepoDB supports MySQL through two separate driver packages — [RepoDb.MySql](https://www.nuget.org/packages/RepoDb.MySql) (built on [MySql.Data](https://www.nuget.org/packages/MySql.Data)) and [RepoDb.MySqlConnector](https://www.nuget.org/packages/RepoDb.MySqlConnector) (built on [MySqlConnector](https://www.nuget.org/packages/MySqlConnector)). Install only the one that matches the ADO.NET driver already used by your application — the classes below are grouped by which package they belong to.
